# Logo

The Promptlings mark (an agent on a slate tile) with the name set in the display face.

- **Provide:** `size` (mark height in px, default 32). `markOnly` drops the name.
- Use it once per screen, top left. Use `markOnly` for favicons, avatars of the official account and anywhere under 120px wide.
- The mark carries its own `tile-floor` ground, so it works on Slate and Paper. The name takes `ink`.
- For print, decks and the X post use the SVG wordmarks in the Logos asset group instead.
- Don't recolour the mark, add effects, or put it on a tile colour.
