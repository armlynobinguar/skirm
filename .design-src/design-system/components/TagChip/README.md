# TagChip

Shows a mechanic tag exactly as the engine names it, with its tag icon.

- **Provide:** `tag` (one of the 10 v0 tags: `spreads`, `liquid`, `damages`, `solid`, `blocks`, `pushable`, `breakable`, `flammable`, `collectible`, `goal`), optional `count`.
- The tooltip carries the tag's meaning from the tags table.
- Use on skill cards (handles), map cards (mechanics in play) and marketplace filters.
- Tags are lowercase mono, never translated or renamed. Don't colour tag chips by tile colour: one tag spans several things.
