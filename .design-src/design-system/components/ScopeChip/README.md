# ScopeChip

Marks build scope: MVP, Stretch or Roadmap, as in the concept doc's system index.

- **Provide:** `scope` (`MVP`, `Stretch`, `Roadmap`).
- Solid border for MVP, dashed for Stretch, dotted for Roadmap, so the three differ without colour.
- Use in docs, the judges' README screenshots and any "coming later" feature in the app (Duel mode, map editor, rentals). Not for player-facing status.
