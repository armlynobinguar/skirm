# Badge

One or two words of status: Cleared, Low credits, Goal flooded, Testnet.

- **Provide:** children, `tone` (`neutral`, `good`, `warning`, `critical`, `you`), optional `icon` (an `Icon` name, or `false` for none), `solid` for a filled badge on busy backgrounds.
- Tone badges show their tone icon automatically, so state never rests on colour alone.
- `you` is a `chalk` badge for marking the viewer in lists.
- Don't use badges as buttons or for counts (use `Tabs` counts or mono text).
