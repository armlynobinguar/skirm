# TileLegend

The key to the board: every thing's swatch, name, map character and tags.

- **Provide:** optional `kinds` (filter, e.g. the things on the current map), `size` (swatch px, default 32), `compact` (smaller swatches, names only).
- Show the full legend in tutorials and the map screen, the compact one under live and PvP boards.
- The tags line matters: skills are written against tags, so players learn tags here.
