# Icons

Stroke icons on a 16-unit grid, 1.5 stroke, round caps and joins, exported at 32px. Single ink `#7a817c`, which holds 3:1 or better on both themes' `bg` and `surface`; an `<img>` cannot take `currentColor`, so in the product use the `Icon` component instead.

- Actions: `move`, `wait`, `pick-up`, `drop`, `place-block` (Builder), `dig` (Digger), `extinguish` (Firefighter).
- Tags: `tag-spreads`, `tag-liquid`, `tag-damages`, `tag-solid`, `tag-blocks`, `tag-pushable`, `tag-breakable`, `tag-flammable`, `tag-collectible`, `tag-goal`.
- Game: `tick`, `steps`, `agent`, `crew`, `skill`, `map`, `credits`, `timer`, `royalty`, `trophy`, `elo`, `pvp`, `wallet`.
- Controls and states: `play`, `pause`, `step-back`, `step-fwd`, `replay`, `plus`, `minus`, `close`, `lock`, `check`, `info`, `warning`, `critical`.
- File names use hyphens; `Icon` names use underscores (`place_block`, `tag_spreads`).
