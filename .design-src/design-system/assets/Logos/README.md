# Logos

- `promptlings-mark.svg`: the mark. An agent (chalk circle, `>_` face) on a `tile-floor` slate tile with one `tile-mark` pink corner bracket. Carries its own ground, so it works on Slate and Paper. Minimum 16px.
- `promptlings-wordmark-dark.svg`: PROMPTLINGS built from tiles on a 5 × 7 grid, the O replaced by an agent. Ink `#f4efe2` (`tile-agent`). Use on Slate (`bg` dark) or any dark ground. Minimum height 14px.
- `promptlings-wordmark-light.svg`: the same in `#1a1f1d` (`ink`, light) with an outlined agent. Use on Paper or any light ground.
- Keep clear space of one tile (a quarter of the mark's height) on every side. Don't recolour, stretch or add effects.
